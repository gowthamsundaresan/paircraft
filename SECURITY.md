# Security policy

## Supported versions

Paircraft is pre-release. Security fixes apply to the current `main` branch only.

## Reporting a vulnerability

Do not open a public issue containing exploit details, secrets, proprietary data, or a
reproduction that could put systems at risk.

When the repository is hosted on GitHub, use its private security-advisory reporting channel.
Until then, contact the repository owner privately and include:

- The affected component and revision.
- Reproduction conditions.
- Expected impact.
- Any suggested mitigation.

Do not include real credentials or third-party private data. Acknowledgement and remediation
timelines will be set when the project establishes an operational security contact.
